# KEDI self-hosted fonts

These unmodified WOFF2 files replace the Google-hosted fonts previously linked in index.html. Family names, normal styles, requested weights, Unicode coverage and font-display: swap are preserved. No font provider connections are needed at runtime.

- IBM Plex Sans: weights 400, 500, 600, 700; Google Fonts distribution v23.
- Space Grotesk: weights 500, 600, 700; Google Fonts distribution v22.
- Both are distributed under SIL Open Font License 1.1; see the accompanying licence files.

Files were obtained on 15 November 2026 from the existing Google Fonts CSS2 request for these families and weights. Repeated weight rules share the original variable-font files. All original language subsets are retained. The PWA precaches the local CSS and WOFF2 assets through the existing build configuration.
